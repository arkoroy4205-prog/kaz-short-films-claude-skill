# Kaz Short Films — Claude Skill

A Claude Skill project for turning a voice-over, SRT subtitles, and a creative brief into a cinematic short-film storyboard and rendered video.

## Intended workflow

1. Upload the narration audio and matching `.srt` subtitle file in Claude.
2. Provide the story/topic prompt and choose **9:16 vertical**, **16:9 landscape**, or both.
3. Claude develops a scene-by-scene storyboard, visual direction, and timing aligned to the narration.
4. Render the storyboard in the selected aspect ratio(s).
